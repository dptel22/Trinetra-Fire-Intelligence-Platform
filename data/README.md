# Data — SIH 2026 PS26162

Runtime data artifacts live here. Everything except `README.md` is gitignored —
large binaries (parquets, DuckDB, CSVs) are regenerated by the pipeline or pulled
from the artifact store.

## Layout
```
data/
├── raw/                                        # gitignored — raw FIRMS API CSV downloads
├── processed/                                  # gitignored — pipeline output parquets
│   ├── sih2026_h3_daily_features_firms.parquet         (~36 MB, FIRMS-only H3-day features)
│   ├── sih2026_h3_daily_features_with_osm_wri.parquet  (~177 MB, + OSM/WRI static joins)
│   └── sih2026_h3_daily_labeled_osi_wri.parquet        (~177 MB, labeled training table)
├── feature_store.duckdb                        # runtime — backend feature store (h3_daily, osm_wri_static)
├── audit_log.duckdb                            # runtime — append-only analyst audit trail
└── README.md
```

## How the pieces connect

- `app/core/config.py` defaults point at these files:
  `H3_DAILY_PARQUET` / `OSMWRI_PARQUET` → `data/processed/*.parquet`,
  `DUCKDB_PATH` → `data/feature_store.duckdb`.
- The DuckDB feature store is seeded from the processed parquets
  (`h3_daily` ← firms parquet, `osm_wri_static` ← osm_wri parquet).
- VIIRS 7-day South Asia CSVs (`J1_VIIRS_C2_South_Asia_7d.csv`,
  `SUOMI_VIIRS_C2_South_Asia_7d.csv`) are tracked in git as small pipeline inputs;
  bulk FIRMS downloads belong in `data/raw/`.

## Data sources

- **FIRMS API**: https://firms.modaps.eosdis.nasa.gov/api/area/
- **VIIRS 375m**: Suomi-NPP (S) and NOAA-20 (J1) satellites
- **MODIS**: Terra (T) and Aqua (A) satellites
- **OSM / WRI**: static land-use and land-cover joins (see
  `notebooks/eda/osi-wri-eda.ipynb`)
